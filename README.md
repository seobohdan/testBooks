# Libri — MVP книжного магазина + админка + интеграция Vendi Libri

## Запуск
    npm install
    npm start
Магазин: http://localhost:3000 · Админка: http://localhost:3000/admin/ (пароль `admin123`)
Свой пароль/порт: `ADMIN_PASSWORD=секрет PORT=8080 npm start`
Данные: `data/db.json` (создаётся при первом запуске, с 6 тестовыми товарами).

## Страницы
index · catalog (поиск/фильтры) · product · cart (оформление заказа) · about

## Интеграция Vendi Libri
1. Импорт (pull): админка → «Интеграция Vendi Libri» → URL, ключ, авторизация, путь к массиву, маппинг полей →
   «Проверить соединение» → «Загрузить товары» → «Импортировать». Есть автосинхронизация. Повтор обновляет, не дублирует.
2. Push: приложение шлёт POST /api/v1/products с X-API-Key (ключ во вкладке «API для приложения»).
По умолчанию подключён встроенный демо-сервер (/mock/vendi-libri, ключ demo-key) — импорт работает сразу.
Для реального Vendi Libri замените Base URL, ключ и маппинг по его документации.
